ОТДЕЛ КАДРОВ ПРЕДПРИЯТИЯ — ASP.NET Core MVC
=============================================

ЧТО ЭТО
-------
Полностью рабочий веб-проект (не WinForms). Не требует конструктора форм
и перетаскивания элементов. Все страницы уже написаны в виде кода.

Функциональность:
- CRUD (добавление/изменение/удаление) для: Работники, Подразделения,
  Должности, Профессии, Образование.
- 5 отчётов на вкладке "Отчёты":
  1. Личная карточка работника
  2. Список сотрудников по подразделениям
  3. Фонд оплаты труда
  4. Распределение по образованию
  5. Штатное расписание
- Экспорт любого сформированного отчёта в Excel (.xlsx).
- База данных SQLite создаётся автоматически при первом запуске
  (файл kadry.db появится рядом с исполняемым файлом).

ТРЕБОВАНИЯ
----------
- .NET 8 SDK (скачать: https://dotnet.microsoft.com/download/dotnet/8.0)
- Либо Visual Studio 2022 (версия 17.8 и новее) с рабочей нагрузкой
  "ASP.NET и веб-разработка".

КАК ЗАПУСТИТЬ
-------------

Вариант А — через терминал (самый быстрый):
1. Установите .NET 8 SDK, если ещё не установлен.
2. Откройте терминал (cmd/PowerShell) в папке с проектом (там, где
   лежит файл Kadry.csproj).
3. Выполните:
       dotnet restore
       dotnet run
4. В консоли появится строка вида:
       Now listening on: http://localhost:5000
   Откройте этот адрес в браузере.

Вариант Б — через Visual Studio:
1. Откройте файл Kadry.csproj двойным кликом — VS сама создаст решение.
2. Дождитесь восстановления NuGet-пакетов (полоска внизу окна).
3. Нажмите F5 (или зелёную кнопку "Запуск").
4. Браузер откроется автоматически на странице приложения.

СТРУКТУРА ПРОЕКТА
------------------
Kadry.csproj              — файл проекта и список NuGet-пакетов
Program.cs                 — точка входа, настройка маршрутов и базы данных
Models/Entities.cs          — сущности: Employee, Department, Position,
                              Profession, Education
Data/AppDbContext.cs        — контекст EF Core (подключение к SQLite)
Controllers/                — вся логика (аналог кнопок btnAdd/btnEdit/btnDelete)
Views/                      — HTML-страницы (аналог форм в WinForms)

ЧАСТЫЕ ВОПРОСЫ
--------------
В: Нужно ли выполнять миграции (Add-Migration)?
О: Нет. Программа при первом запуске сама создаёт файл kadry.db со всеми
   таблицами (EnsureCreated в Program.cs).

В: Как изменить порт?
О: dotnet run --urls "http://localhost:5050"

В: Оклад не сохраняется / ошибка формата числа.
О: Вводите число с точкой в качестве десятичного разделителя, например
   55000.50, либо смените региональные настройки системы на en-US,
   либо согласуйте формат ввода с преподавателем.

В: Как добавить свой пункт в отчёты?
О: В Controllers/ReportsController.cs добавьте новый case в метод
   BuildReport и соответствующий метод Build..., а в
   Views/Reports/Index.cshtml — новую строку <option> в select.
